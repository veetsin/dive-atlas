# data/

三个文件，全部是 UTF-8 JSON，中英双语字段写成 `{ "zh": "…", "en": "…" }`。字段定义见 `docs/SPEC.md` §7。

| 文件 | 内容 | 维护方式 |
|---|---|---|
| `sites.json` | 潜点 | 手工编辑；改完跑 `npm run data:pinyin && npm run data:validate` |
| `species.json` | 物种（贴纸 id、体型等级） | 先定潜点，再从潜点里统计出需要的物种 |
| `regions.json` | 区域（聚合气泡、筛选、标记颜色） | 基本固定 |

## 当前状态

`sites.json` 里的 14 条是**格式示例种子**：数值是常见说法，`verified: false`，`sources` 为空。
正式数据工作（M2 里程碑）要逐条核实、补来源，再把 `verified` 改为 `true`。

## 核实标准

- 每条至少 2 个独立来源交叉（公园管理处 / 旅游局 / 权威潜水媒体 / 船宿运营商官网）。
- 季节写"主流说法"；有争议的写进 `notes`，页面不显示 `notes`。
- 坐标精确到 0.01°（约 1 km）即可，指向主要潜点或码头所在位置。
- 文案自己写，不复制任何来源的句子；不用"世界最佳""必去"等绝对词。
